# 扫频模块参数说明

仅在用户询问、校验或要求修改专业扫频参数时阅读本文档。扫频模块选择和标准案例参数
已在 `SKILL.md` 中定义，本文不重复。

## 扰动注入设置

| 参数 | 类型/单位 | 元件参考默认值 | 含义与选择要点 |
| --- | --- | --- | --- |
| `Mag` | 实数；V 或 A | 电压模块：`20`；电流模块：`0.1` | 扰动幅值。增大可提高相对数值噪声的可辨识度，但过大可能改变工作点，不再代表小扰动特性。结合目标元件额定量、运行点和工程限值选择。 |
| `InitTime` | 实数，s | `5` | 扰动注入起始时刻，应为模型初始化和暂态衰减预留时间。增加该值会直接增加总仿真时长。 |
| `RampTime` | 实数，s | `0` | 开始扰动时的斜坡注入时间，用于减小突变。元件元数据未定义它与 `RampRatio` 的内部优先关系，不要视为等价参数。 |
| `Sequence` | 选择项 | `0` | `0`：A 相阻抗；`1`：正序阻抗；`2`：负序阻抗。根据研究对象选择。 |

## 三段频率设置

| 参数 | 类型/单位 | 元件参考默认值 | 含义 |
| --- | --- | --- | --- |
| `InitVal1` | 实数，Hz | `1` | 第一段起始频率 |
| `EndVal1` | 实数，Hz | `10` | 第一段结束频率，也是当前流程中第二段的有效起点 |
| `DeltaStep1` | 实数，Hz | `0.1` | 第一段频率间隔 |
| `DeltaTime1` | 实数，s | `10` | 第一段每个频率点的驻留时间 |
| `InitVal2` | 实数，Hz | 空，界面隐藏 | 第二段兼容字段；当前时长和解析算法不用它确定边界 |
| `EndVal2` | 实数，Hz | `100` | 第二段结束频率，也是当前流程中第三段的有效起点 |
| `DeltaStep2` | 实数，Hz | `1` | 第二段频率间隔 |
| `DeltaTime2` | 实数，s | `2` | 第二段每个频率点的驻留时间 |
| `InitVal3` | 实数，Hz | 空，界面隐藏 | 第三段兼容字段；当前时长和解析算法不用它确定边界 |
| `EndVal3` | 实数，Hz | `1000` | 第三段结束频率 |
| `DeltaStep3` | 实数，Hz | `10` | 第三段频率间隔 |
| `DeltaTime3` | 实数，s | `1` | 第三段每个频率点的驻留时间 |
| `RampRatio` | 实数，无量纲 | `0.2` | 每个驻留区间用于斜坡注入的时间比例，范围为 `0 < RampRatio <= 1`。比例越大，切换越平缓，但稳定测量时间越短。 |

## 测试开关

| 参数 | 类型 | 元件参考默认值 | 含义 |
| --- | --- | --- | --- |
| `UnitTest` | 逻辑选择 | `0` | `0`：禁用；`1`：启用。正常扫频使用 `0`，只有明确测试扫频元件本身时才启用。 |

## 参数关系与校验

- 最终参数字典必须包含全部 18 个字段。先使用 `SKILL.md` 中对应注入类型的完整标准字典，再合并用户明确提供的覆盖项。
- 当前有效频率边界依次为 `InitVal1 -> EndVal1 -> EndVal2 -> EndVal3`。`InitVal2`、`InitVal3` 是隐藏兼容字段，当前解析器不把它们作为第二、第三段起点。
- 必须满足 `InitVal1 < EndVal1 < EndVal2 < EndVal3`，所有 `DeltaStepN > 0`、`DeltaTimeN > 0`。
- 优先让每段频率跨度是相应步长的整数倍。解析器会对点数取整，非整数倍可能导致预期点数与实际扫频不一致。
- 减小步长会提高频率分辨率，同时增加点数和仿真时长；增加驻留时间有助于响应稳定，也会累计增加计算成本。
- 解析器在每个驻留区间末尾取约 10% 的样本做平均。确保 `sample_freq * DeltaTimeN` 足以产生非零平均窗口。
- `Sequence` 只能取 `0`、`1`、`2`；`RampRatio` 必须在 `(0, 1]`；`UnitTest` 只能取 `0` 或 `1`。
- 参数覆盖后必须用最终数值字典重新计算仿真结束时间，并把同一字典传给结果解析器。
- 传给注入元件时把参数值转换为字符串；数值字典继续用于校验、时长计算和解析。

## 标准案例的既定裁定

- 标准案例（`SKILL.md` 和完整案例）的 `Sequence` 固定为 `1`（正序阻抗），与 `src/sweepanalysis/sim_result_analysis.py` 参考流程一致；宽频阻抗扫描通常关注正序网络特性。用户未指明时不要静默改回 `0`。
- I 型标准频段为 `10–70 / 200 / 2000 Hz`。`src/sweepanalysis/sim_result_analysis.py` 中更窄的 `10–40 / 60 / 80 Hz` 属于特定实验配置，不是标准案例；用户要求该频段时作为显式覆盖项处理。

## 向用户解释和追问

用户不熟悉参数时，优先确认：

1. 测量 A 相、正序还是负序；
2. 关注的最低/最高频率、分辨率或重点频段；
3. 每个频率点需要的稳定时间，以及仿真时长或计算成本限制；
4. 扰动幅值的工程限值、目标元件额定量和当前运行点。

信息不足时可将 `SKILL.md` 中的标准参数作为可编辑起点，但必须说明它不是对所有模型
都安全或最优的工程建议。不要仅根据元件参考默认值断言 `Mag`、起始时间或驻留时间
适合目标系统。
